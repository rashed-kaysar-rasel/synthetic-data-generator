# Quickstart: Saved Generation Configurations

## Goal
Allow logged-in users to save and import generator configurations.

## Prerequisites
- App running locally.
- A user account to log in.

## Steps
1. Log in to the application.
2. Upload a schema and configure row counts and providers.
3. Save the configuration with a unique name.
4. Reload the page and import the saved configuration (schema must match).
5. Confirm the generator form is populated with the saved values.

## Expected Results
- Saved configurations appear in the user’s list.
- Importing a configuration pre-fills the generator form when the schema matches.
- Guests do not see save/import options.
